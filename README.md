# 💰 六账户记账（Six-Account Ledger）

一个**零依赖、单文件、手机优先**的记账网页应用。打开即用，数据存在本机，账目永不联网。

在线使用：<https://six-account-ledger.app.workbuddy.host/?sharecode=UCEDANRFCB>

---

## 💡 想法的来源

这个产品诞生于一次读书实践。

我读了 **《有钱人和你想的不一样》**（Secrets of the Millionaire Mind，作者：**哈维·艾克 T. Harv Eker**）。书中的"财富档案"提出了一套**六账户金钱管理法**：每笔收入按比例分进六个账户——

> 🏆 财务自由账户（10%）｜🎮 玩乐账户（10%）｜🏦 长期储蓄账户（10%）｜📚 教育账户（10%）｜🍚 需求账户（50%）｜🎁 付出账户（10%）

书里的方法很打动我，但有个现实问题：**每次花钱前手动"分钱"，坚持不了几天。**

于是产生了这个想法：**把"分钱"自动化——每记一笔消费，自动归入对应账户，并实时对照当月预算。** 记账本身就该是这六个账户的执行器。

这套"账户＋预算"的设计来自那本书；"自动执行"的思路来自另一个读书心得：改变行为靠重新设计默认选项，不靠每天硬扛意志力。两者合起来，就是你现在看到的这个应用。

本应用由 AI 助手（WorkBuddy · 书童）根据这个想法协助开发完成。

## ✨ 功能

- **六账户体系**：每笔消费（金额＋名称）归入六个账户之一，自动累计
- **月度预算**：每个账户设每月预算，进度条实时显示"花了 / 剩多少 / 超支"
- **流水查询**：按日期倒序查看每笔记录，可删除
- **月份切换**：回看任意月份的支出结构
- **数据备份**：一键导出 / 导入 JSON，防数据丢失
- **数据本地化**：所有数据存在设备浏览器（localStorage）中，**不上传任何服务器**

默认预算按学生月生活费 2000 元示例：财务自由 200 / 玩乐 200 / 长期储蓄 200 / 教育 200 / 需求 1100 / 付出 100（可在设置中任意修改）。

## 📱 使用方法

1. 手机浏览器打开 `index.html`（或上方在线链接）
2. 浏览器菜单 → **添加到主屏幕**，即可像 App 一样使用
3. 月底在「设置 → 数据备份」导出 JSON 文本，存一份——数据在本机，备份在手，两全

## 🛠 技术说明

- **单文件** `index.html`，原生 HTML/CSS/JavaScript，无框架、无依赖、无构建
- 数据存储：浏览器 localStorage
- 欢迎按自己的账户比例修改 `DEF` 常量后自用
